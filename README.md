# Natura hair

架空の美容室「Natura hair」を想定して制作したWebサイトです。

## 概要

20代後半〜40代の女性をターゲットとした美容室のWebサイトを想定して制作しました。

自然体の美しさを大切にするサロンをイメージし、
アイボリーやブラウンを基調とした、落ち着きと柔らかさを感じられるデザインを意識しています。

## 使用技術

- HTML
- CSS
- JavaScript

## 実装内容

- レスポンシブ対応
- ハンバーガーメニュー
- ページ内リンクによるナビゲーション
- スクロールに応じたフェードインアニメーション
- ギャラリー画像の順次表示アニメーション
- ギャラリー画像のホバーアニメーション

## 制作のポイント

PCだけでなくスマートフォンからでも見やすいよう、
画面幅に応じてレイアウトが変化するレスポンシブ対応を行いました。

スマートフォンではハンバーガーメニューを実装し、
限られた画面幅でも操作しやすいナビゲーションを意識しています。

また、JavaScriptのIntersection Observer APIを使用し、
スクロールに合わせたフェードインアニメーションを実装しました。

ギャラリーでは、画面内に入ったタイミングで画像が順番に表示されるようにし、
シンプルなデザインの中にも動きを取り入れています。

デザイン面では、美容室の落ち着いた雰囲気に合わせて、
余白や写真を大きく活かしながら、アイボリーとブラウンを基調とした
柔らかく上品なレイアウトを意識しました。
